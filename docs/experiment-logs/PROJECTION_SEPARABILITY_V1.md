# 2D Projection Separability V1

日期：2026-09-18

目标：验证从 BrPCD 点云生成的三视图正交投影是否能稳定保留
`girder / pier / deck` 的构件区分度。

说明：本诊断把每个 3D 点回投到像素，使用该像素的多数标签
预测这个点，再与点级真值比较。因此结果代表**2D 标签图本身的
可分性上限**，不是训练后的 2D 模型结果，也没有使用 3D 网络预测。

## 判读标准

- `majority_vote` 明显高于单视图：三视图具有互补性，值得训练 2D 分支。
- `pier / deck` 的多数像素标签 IoU 很低且 mixed-pixel fraction 高：构件在投影中严重重叠，单纯 2D 融合可靠性有限。
- 投影标签图使用真值生成，因此这里测的是可用信息上限；真实优势仍需 2D 模型交叉验证。
